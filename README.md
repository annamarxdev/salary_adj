Progressive Salary Adjustment
A company decided to grant a salary increase to its employees based on the following brackets:
Salaries up to R$ 1,500.00: 15% increase
Salaries from R$ 1,500.01 to R$ 3,000.00: 10% increase
Salaries above R$ 3,000.00: 5% increase
My program takes the current salary as input, calculates the increase amount and the new salary, and displays all this information on the screen.
